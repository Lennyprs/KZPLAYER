KZ PLAYER - RETOUR 3.5.6 SANS DESINSTALLATION - V122

IMPORTANT : ce ZIP contient les SOURCES, pas un APK compile.
Il remet le code Android de la V120 / 3.5.6, apres installation de la 3.5.7.
Ne desinstalle pas l'application et n'efface pas ses donnees.

1. Extraire ce ZIP puis copier son contenu A LA RACINE du depot local KZPLAYER,
   en remplacant les fichiers existants. Ne pas creer de sous-dossier contenant
   un deuxieme projet. Le dossier app et le dossier .github doivent etre copies.
   Remplacer aussi les quatre fichiers ReplayCatchup.java, ReplayXmltv.java,
   ReplayStalker.java et ReplaySources.kt : ils sont volontairement neutralises.
   Cela annule les ajouts V121 sans devoir supprimer manuellement leurs fichiers.
   Les anciens guides V121 eventuellement presents sont historiques, pas actifs.

2. Depuis le terminal ouvert dans ce depot, executer ces TROIS lignes :

git add app/build.gradle app/src/main/java/com/kzplayer/app .github/workflows/build-apk-signed.yml tools/release/next_official_version.py A-LIRE-RETOUR-3.5.6-V122.txt
git commit -m "Retablit la 3.5.6 en mise a jour sans desinstallation - V122"
git push

3. Sur GitHub / Lennyprs / KZPLAYER / Actions, attendre la NOUVELLE execution
   de Build KZ Player APK (signed), declenchee par ce push. Ne pas relancer
   une ancienne execution 3.5.7. Si elle echoue, ne rien desinstaller : transmettre
   le message d'erreur. Aucune installation n'a lieu tant que tu ne l'acceptes pas.

4. Une fois la nouvelle compilation verte, ouvrir sa nouvelle release GitHub
   affichant KZ Player 3.5.6 et telecharger app-release-signed.apk.
   Le copier sur la TV si necessaire, puis l'ouvrir et choisir Mettre a jour.
   Il doit s'installer PAR-DESSUS la 3.5.7. Si Android demande une desinstallation,
   annuler et transmettre le message : ne pas supprimer les donnees.
