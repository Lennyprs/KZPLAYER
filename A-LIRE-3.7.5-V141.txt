GARDE-FOUS CONSERVÉS PAR RAPPORT À UN REMPLACEMENT AVEUGLE
-------------------------------------------------------
Cette livraison fusionne le pipeline de référence avec les fonctionnalités récentes ;
PlayerActivity.kt n'est donc pas intégralement remplacé par le fichier historique.
- Les paramètres de requête opaques (tokens, identifiants/signatures) ne sont
  jamais modifiés par les variantes de transport.
- Pas de carrousel VOD de variantes sur refus 401/403/429/503/512. Les reprises
  d'authentification déjà bornées restent en place ; pas de nouvelle sonde initiale.
- Le watchdog de démarrage VOD qui changeait de signature au bout de 9 secondes
  n'est pas réactivé. Les changements de source ne servent qu'après erreur réelle.
- Les protections replay (limitation HTTP 429/Retry-After, archives et interdiction
  de basculement involontaire vers le direct, reprises spécifiques) sont conservées.
- Historique isolé par liste propriétaire, bonne reprise, identité de l'épisode
  suivant, sous-titres, reprise après pause d'activité et fenêtre d'erreur sûre conservés.
- Le diagnostic sans URL ni identifiants reste disponible en cas d'erreur.
- Les méthodes de construction des mini-lecteurs live sont inchangées par rapport
  à la référence locale historique vérifiée. Leurs ajouts de récents, propriétaires
  et navigation ne sont pas annulés. La preuve Git à l'octet près concerne le
  PlayerActivity.kt du build nº 38, pas tous les fichiers historiques du dépôt.

INSTALLATION — IMPORTANT
-----------------------
1. Extraire ce ZIP COMPLET à la racine du dépôt local KZPLAYER (dossier contenant
   app, tools, .github et build.gradle). Accepter les remplacements.
2. Dans cette racine, exécuter :

   python3 tools/release/remove_libvlc_v135.py

   Le script garde son nom historique, mais est actualisé pour 3.7.5 : il retire
   les vieux fichiers VLC ET les fabriques/essais VOD V135–V139 devenus inutiles.
   Ne pas sauter cette étape : une extraction ZIP ne supprime pas les anciens
   fichiers du dépôt. Le nettoyage est limité à une liste fixe et relançable.
3. Puis exactement ces trois commandes Git :

   git add -A app tools/release/remove_libvlc_v135.py A-LIRE-3.7.5-V141.txt REFERENCE-LECTURE-V112.json
   git commit -m "Restaure le lecteur V112 en conservant les ameliorations - 3.7.5"
   git push

4. Attendre que le workflow Android officiel soit entièrement vert.
5. Installer le nouvel APK officiel en mise à jour SANS désinstaller, sans effacer
   les données et sans changer de signature. Vérifier la version affichée : 3.7.5.
   Les APK personnalisés restent dans leur circuit de build/identité propre.
6. Vérifier la lecture du même contenu qui fonctionne sur la 3.5.0 de référence.
La procédure ADB peut rester en pause pour cette restauration.
Les autres guides inclus sont historiques ; suivre celui-ci pour cette version.
